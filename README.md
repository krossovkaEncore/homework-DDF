# 4. Приводим к 3НФ
В таблице **"Заказы"** есть зависимость:
> ID_заказа -> Клиент -> Телефон
То есть телефон определяется клиентом, а не непосредственно заказом.
Поэтому клиента тоже выносим в отдельную таблицу.
