# РАЗДЕЛ 2. Моделирование таблиц и связей

#### Тема уроков 7 - 8. Создание связей между сущностями.

**Домашняя работа:**
**Задание к уроку 7 - 8**

### Анализ предметной области

В качестве предметной области рассмотрим **музей**. Для автоматизации работы музея необходимо выделить основные сущности, которые могут храниться в отдельных таблицах базы данных.

### Список сущностей

1. **Музей**
   *(FK: филиалы, залы, сотрудники, выставки)*

2. **Филиал**
   *(FK: музей, залы, сотрудники, выставки)*

3. **Зал**
   *(FK: филиал, экспонаты, выставки)*

4. **Экспонат**
   *(FK: зал, коллекция, автор, выставка)*

5. **Коллекция**
   *(FK: музей, экспонаты)*

6. **Автор**
   *(FK: экспонаты)*

7. **Выставка**
   *(FK: музей, зал, экспонаты, сотрудники)*

8. **Сотрудник**
   *(FK: музей, филиал, выставки, должность)*

9. **Должность**
   *(FK: сотрудники)*

10. **Посетитель**
    *(FK: билеты, экскурсии)*

11. **Билет**
    *(FK: посетитель, выставка, сеанс)*

12. **Экскурсия**
    *(FK: посетитель, сотрудник, выставка)*

13. **Экскурсовод**
    *(FK: сотрудник, экскурсия)*

14. **Сеанс**
    *(FK: выставка, билеты)*

15. **Реставрация**
    *(FK: экспонат, сотрудник)*

16. **Сотрудник реставрации**
    *(FK: сотрудник, реставрация)*

17. **Партнёрская организация**
    *(FK: музей, выставки)*

18. **Мероприятие**
    *(FK: музей, выставка, сотрудники, посетители)*

### Основные связи между сущностями

* Один **музей** может иметь несколько **филиалов**.
* Один **филиал** может содержать несколько **залов**.
* Один **зал** может содержать несколько **экспонатов**.
* Один **автор** может иметь несколько **экспонатов**.
* Одна **коллекция** может содержать несколько **экспонатов**.
* Один **музей** может проводить несколько **выставок**.
* Одна **выставка** может проходить в нескольких **залах**.
* Один **сотрудник** может участвовать в нескольких **выставках** и **экскурсиях**.
* Один **посетитель** может приобрести несколько **билетов**.
* Один **билет** относится к определённому **сеансу** или **выставке**.
* Одна **экскурсия** проводится определённым **экскурсоводом** и может включать нескольких **посетителей**.
* Один **экспонат** может несколько раз передаваться на **реставрацию**.
* Один **музей** может сотрудничать с несколькими **партнёрскими организациями**.
* Один **музей** может проводить множество **мероприятий**.

### Вывод

В результате анализа предметной области было выделено **18 основных сущностей**, которые могут быть представлены отдельными таблицами в базе данных. Между таблицами необходимо создать связи с помощью **первичных (PK)** и **внешних ключей (FK)**. Это позволит связать экспонаты с коллекциями и авторами, сотрудников с музеем и выставками, а посетителей с билетами и мероприятиями.
